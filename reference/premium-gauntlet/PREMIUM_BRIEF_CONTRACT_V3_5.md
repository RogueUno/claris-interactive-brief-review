# CLARIS Premium Brief Contract V3.5

## Core rule
Only booking/prospect evidence can create a discovery dimension. Public research can sharpen an admitted dimension but cannot create a commercial, organizational or timing unknown.

## Main vs expandable
The main brief is a 5-minute decision memo. It contains only facts and observations that change the call.
Proof depth is expandable:
- E# Evidence = source -> admitted fact -> used for -> not used for
- R# Reasoning = premises -> bounded observation -> not a claim of
- U# Unknown = why unresolved -> what resolves -> conclusions blocked

## Sparse-booking behavior
For "Interested in discussing API security", the admitted dimensions are:
- D1 TECHNICAL_SCOPE
- D2 DESIRED_OUTCOME

No other discovery dimension is allowed until prospect/booking evidence exposes it.

## Question budget
Default exactly one question per admitted dimension. Extra questions require a genuinely new admitted dimension or a necessary technical drill-down.

## Signal budget
Four signals in the Resend fixture. Overlapping technical details must be synthesized; low-value protocol trivia remains in Evidence blocks.

## Hypothesis budget
0-2. Never generate hypotheses merely to fill a section.

## Service mapping
Service paths are conditional mappings from prospect-confirmed D1/D2 answers. They never become recommendations before confirmation.

## Promotion gate
Do not promote into frozen PREPARE/FINALIZE until:
1. Resend gold V2 is matched or exceeded;
2. a second real-company fixture passes;
3. no hypothesis/public fact can affect deterministic scoring;
4. expandable provenance is rendered in the product surface;
5. a human review judges the main brief materially useful immediately before a call.
