## Epistemic Architecture & Security Notice
- **Zero Live API Execution**: Static, frozen governed intelligence objects only.
- **Zero Secrets / Backend**: Client-side single-page presentation.
- **Single-Authority Invariant**: Data objects are directly generated from the canonical assurance and service-fit pipeline replay.
